# Natural Language Processing (NLP) with Python

A beginner-friendly collection of NLP notebooks demonstrating the fundamentals of **Word Embeddings**, **Word2Vec**, and **Amazon Review Text Analysis** using Python.

This repository is designed for students and beginners who want to understand how computers convert text into meaningful numerical representations for machine learning and deep learning applications.

---

## 📚 Repository Contents

### 1. Word Embedding (`Word_embedding.ipynb`)

Learn the basic concepts of word embeddings using TensorFlow/Keras.

Topics covered:

* Introduction to Word Embeddings
* Integer Encoding
* One-Hot Encoding
* Keras Tokenizer
* Vocabulary Creation
* Sequence Conversion
* Padding Sequences
* Embedding Layer
* Preparing text for Deep Learning models

---

### 2. Word2Vec using Gensim (`word_to_vector_gensim.ipynb`)

Understand how Word2Vec creates meaningful vector representations of words using the Gensim library.

Topics covered:

* Loading and preprocessing text data
* Text cleaning
* Tokenization
* Training a Word2Vec model
* Word vectors
* Similar words
* Cosine similarity
* Exploring semantic relationships

---

### 3. Amazon Sports & Outdoors Review Analysis (`Amazon_Sports_Outdoor.ipynb`)

A practical NLP case study using Amazon product reviews.

Topics covered:

* Loading Amazon review dataset
* Text preprocessing
* Training a Word2Vec model
* Finding similar words
* Word similarity analysis
* Understanding semantic relationships in customer reviews

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/<your-username>/NLP.git
```

2. Navigate to the project folder:

```bash
cd NLP
```

3. Install the required libraries:

```bash
pip install numpy pandas gensim tensorflow nltk
```

4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open any notebook and run the cells sequentially.
