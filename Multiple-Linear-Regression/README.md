# 🏡 Multiple Linear Regression – Housing Case Study

A beginner-friendly Jupyter Notebook that explains the complete **Multiple Linear Regression** workflow using a real-world housing dataset.

---

## 📖 Project Overview

This notebook covers the complete regression process, including:

* 📊 Understanding the dataset
* 🔍 Exploratory Data Analysis (EDA)
* 🏷️ Encoding categorical variables
* ✂️ Train-Test Split
* ⚖️ Feature Scaling
* 📈 Building Multiple Linear Regression models
* 🎯 Feature Selection (RFE & VIF)
* 📉 Residual Analysis
* ✅ Model Evaluation

---

## 📂 Project Files

* **Merged_Multiple_Linear_Regression_Housing_Case_Study.ipynb** – Complete notebook
* **Housing.csv** – Dataset used for analysis

---

## 🎯 What You'll Learn

After completing this notebook, you will be able to:

* Prepare data for regression models
* Handle categorical variables
* Build and interpret linear regression models
* Detect multicollinearity using VIF
* Analyze residuals and validate model assumptions
* Evaluate model performance using **R², RMSE, and MAE**

---

## ▶️ How to Run

1. Open the notebook in **Jupyter Notebook** or **VS Code**.
2. Place `Housing.csv` in the same folder as the notebook.
3. Run all cells in order.
